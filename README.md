# SynLab — The Portable Lab

**Making scientific exploration more accessible, practical, and portable.**

SynLab is a portable, modular laboratory system designed to make hands-on experimentation more accessible beyond traditional laboratory environments.

It combines hardware, electronics, sensors, software and digital interfaces into a compact platform for experimentation, observation, monitoring and selected automation.

[![DOI](https://img.shields.io/badge/DOI-10.69687%2Fvaf.2026.1.3-blue)](https://doi.org/10.69687/vaf.2026.1.3)

## About SynLab

Traditional laboratories can be limited by availability, fixed schedules, equipment access and infrastructure requirements.

SynLab explores an alternative through a portable and modular approach. Its architecture is built around a central hub and detachable experiment zones, allowing different modules to be connected and used for practical experiments.

The project combines:

- **Hardware and Electronics:** ESP32-based control and integrated electronic components.
- **Sensors and Data Acquisition:** Environmental sensing and real-time data collection.
- **Software and Connectivity:** Web-based and Bluetooth interfaces for monitoring and interaction.
- **Modular Experimentation:** Detachable and expandable experiment zones.
- **Observation and Automation:** Tools that support practical experimentation and monitoring.
